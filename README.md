# One Line of Earned Pride

A deterministic entry for the make.fun bounty
`u-mang-one-line-of-earned-pride-a0138557`.

The program writes one line of text (1-240 characters) to
`/output/entry.txt`. It uses only the Python standard library and reads no
other file from this repository.

## Run

```sh
python3 main.py
```

Then read `/output/entry.txt`.
